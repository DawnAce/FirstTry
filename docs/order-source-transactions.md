# 订单来源交易与运费关联

一个业务订单可关联多笔平台交易。原始交易和版本独立保留；运费不创建刊物明细，也不增加订阅份数。

## 实施进度

- [x] 来源模型、原件版本、关联记录和审计表。
- [x] CBJ / 淘宝解析保存原始字段、文件名、工作表及行号。
- [x] 纯运费、无法建订阅的退款交易在确认后独立留存。
- [x] 重导去重、来源变化逐笔核对、并发保护、失败保留预览。
- [x] 来源台账、待关联筛选、详情、原始版本及历史原文检索。
- [x] 候选订阅匹配、金额分配、关联与解除历史。
- [x] 主订单和全局搜索覆盖关联交易并展开命中原件。
- [ ] 来源退款核对、业务金额汇总与独立投递变更确认。

## 数据与操作约束

身份键为平台、店铺、原始单号。原始版本保存解析前字段及解析结果；原件文本属于业务数据，不作为系统指令。换文件名或行位置不单独制造交易变更。

确认导入同时写订单和来源，失败全部回滚，成功才消费会话。旧订单重新上传时可补留原件并建立来源关联，不覆盖旧订单人工修改。未重新提供原表的旧订单，缺失原文不得伪造。

纯运费可没有订阅或订期，不生成履约目标。退款状态与退款流水分离；缺少退款金额和日期时保留原状态、金额待核。来源更新不自动修改主订阅金额、状态或投递。有来源或关联历史的订单禁止硬删除，需要停发时使用现有作废流程。

## 后续验收

三项收件信息完整一致、候选唯一才能标记高度匹配，日期仅参与排序。候选覆盖已有订单和同批导入订单。关联精确到订阅明细及收件目标，跨单分配金额合计必须等于来源付款额。退款单可关联留档，不自动将主单标为退款或转中通。

关联与转投分开确认；核对刊期、邮局截止及中通起始，保留履约版本、已发货历史和报数。搜索覆盖原始单号、收件信息、商品及备注，在分页前筛选去重。

## 关联与搜索

管理员在来源详情打开“查找或更正关联订阅”，确认具体明细、收件目标及分配金额，再预览和保存。允许一笔运费跨订阅分配，合计等于原付款额；退款另行核对。候选覆盖系统已有订阅与本批确认导入后的订阅，不从补拍数量推断份数。缺少资料、多个完整匹配、已退款或取消的主订阅均仅提示疑似。

关联会核对来源编辑版本和候选订阅签名，资料变化、旧目标、作废订单均阻断。解除或更正保留旧关联。搜索主订单、来源台账和全局搜索均覆盖所有原件版本；主列表显示来源笔数，未关联交易单独显示入口。
